# ClassTrack Database

## Database Technology

* SQL Server
* SQL Server Instance: `.\SQL2025`
* Database Name: `ClassTrackDb`
* Authentication: Windows Authentication
* Entity Framework Core used for database access

## Main Tables

* Students
* Teachers
* Attendance
* Fees
* Users

## Database Features

* Student management
* Teacher management
* Attendance tracking
* Fee management
* User authentication
* Role information for users
* Entity Framework Core migrations

## Security

Database connection details and application secrets are maintained locally and are not committed to GitHub.

## Future Enhancements

* Database deployment to Azure SQL Database
* Additional role-based access
* Reporting and analytics
